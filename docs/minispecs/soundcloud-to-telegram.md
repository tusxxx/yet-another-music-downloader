# Goal

Публикация треков без сервера, webhook и постоянно работающего процесса бота.

# Required behavior

- На вход принимаются ссылки на публичные треки или плейлисты SoundCloud. Дополнительные источники YouTube описаны в [youtube.md](youtube.md).
- Один запуск: скачать → подготовить MP3 → отправить треки по очереди через sendAudio → завершиться.
- Название и исполнитель сопровождают аудио; ссылка на источник в сообщение не добавляется.
- Токен бота и канал задаются через общие настройки, переменные окружения или локальный .env; секреты исключены из Git и логов. Настройка в CLI/TUI описана в [settings-and-distribution.md](settings-and-distribution.md).
- Бот заранее создан через BotFather и добавлен администратором канала с правом публикации.
- Ошибка отдельного трека не останавливает остальные; итоговая сводка и ненулевой код завершения при ошибках.
- Файлы выше безопасного порога 49 000 000 байт пропускаются с понятной ошибкой, без скрытой потери качества.
- Временные файлы удаляются после обработки, включая ошибочные запуски.

# Constraints and decisions

- Python CLI, yt-dlp для скачивания, локальный FFmpeg для MP3, HTTPS Telegram Bot API для отправки.
- Нет polling, webhook, сервера и пользовательской Telegram-сессии.
- Загрузка только доступного пользователю контента; обход DRM, платного доступа и авторизации не предусмотрен.
- Повтор отправки после неоднозначного сетевого сбоя не автоматический: Telegram мог уже опубликовать файл.
- Постоянная история и дедупликация между запусками в первую версию не входят; повторный запуск публикует повторно.

# Acceptance criteria

- Документированы установка, FFmpeg, создание бота, права в канале и пример запуска.
- CLI проверяет конфигурацию, доступ к каналу и права бота до скачивания; токен не печатается.
- Проверены CLI help и компиляция Python; реальная публикация проверяется только при наличии предоставленных пользователем настроек.

# Verification

- Успешны: py_compile, CLI --help, установка зависимостей в .venv и pip check.
- Реальная загрузка из SoundCloud и публикация не запускались: отдельная ссылка для проверки не предоставлена, побочных публикаций при установке нет.

# Assumptions

- Изначальная версия — консольная программа для локального запуска. Расширение терминальным UI описано в [tui.md](tui.md); планировщик не входит в текущий объём.
- Приватные треки, лайки и полная синхронизация профиля не входят в первую версию.
