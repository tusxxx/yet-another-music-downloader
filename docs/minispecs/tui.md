# Goal

Отправлять музыку из терминала без обязательного ввода аргументов командной строки.

# Required behavior

- Запуск без аргументов в интерактивном терминале открывает TUI; запуск со ссылками сохраняет обычный CLI. Флаг --tui явно открывает интерфейс.
- Форма содержит многострочный ввод ссылок SoundCloud / YouTube, необязательную многострочную приписку, кнопку «Загрузить список» и отдельную кнопку «Отправить».
- Кнопка «Очистить» рядом с полем ссылок сбрасывает ссылки, треки и переименования, не меняя приписку; недоступна во время работы.
- До публикации загружается список треков (включая содержимое плейлистов). Название каждого трека можно редактировать отдельно; по умолчанию используется оригинальное.
- Изменённое название применяется к title Telegram, подписи и имени прикреплённого MP3. Недопустимые символы имени файла заменяются; локальный временный путь не зависит от пользовательского ввода.
- Пустое поле названия возвращает оригинал. Правки сохраняются при переключении трека и перед отправкой; изменение исходных ссылок сбрасывает подготовленный список.
- Приписка по умолчанию пустая при каждом запуске и не сохраняется между запусками.
- Подпись содержит исполнителя и название, без ссылки на источник. Непустая приписка добавляется через пустую строку в caption каждого аудиосообщения текущей очереди.
- CLI получает аналогичную возможность через --note; без него подпись остаётся прежней.
- Длина итоговой подписи проверяется до отправки каждого трека по лимиту Telegram; длинная приписка не обрезается молча. Трек с превышением лимита не публикуется, остальные продолжают обрабатываться.
- Во время работы видны текущий этап, результаты отдельных треков и итоговые счётчики; повторный запуск очереди и редактирование блокируются до завершения.
- Выход во время работы требует подтверждения и ожидает завершения текущей операции/трека; затем очередь останавливается. Пользователь предупреждается о возможной публикации текущего трека. Автоматического повтора отправки нет.

# Constraints and decisions

- Используется Textual для полноэкранного TUI; существующая логика загрузки и отправки переиспользуется, сетевые операции не блокируют UI.
- Настройки Telegram читаются из общего модуля конфигурации; секреты не отображаются. Экран настроек и поставка описаны в [settings-and-distribution.md](settings-and-distribution.md).
- Без терминала и без ссылок выводится понятная ошибка вместо запуска TUI.
- Дополнительные идеи (история, исключение треков из списка, планировщик) не входят в базовую реализацию.

# Acceptance criteria

- Работают запуск TUI, ввод нескольких ссылок, пустая и непустая приписка, отдельное переименование треков, отображение прогресса и ошибок.
- Обычный CLI совместим с прежним запуском; работают --help и --note.
- Выполнены проверка синтаксиса, зависимостей и локальная проверка интерфейса без публикации; реальная публикация требует отдельного согласования.

# Verification

- Успешны py_compile обоих модулей, CLI --help, pip check и проверка отказа запуска TUI без терминала (код 2).
- Headless-проверка Textual на 100×45 и 80×24: пустая приписка, редактирование отдельных названий, возврат оригинала, сброс списка после изменения ссылок, диалог выхода и завершение работы при открытом диалоге.
- Локальная проверка с подменой загрузчика и Telegram: изменённое title, имя MP3, приписка, этап конвертации и удаление временных файлов.
- Проверено отклонение слишком длинной подписи, включая emoji. Реальные скачивание и публикация не запускались.
- Для расширения YouTube проверены смешанные источники и клик по «Очистить» на 100×45 и 80×24: очищаются ссылки/треки/переименования, сохраняется приписка, фокус возвращается к ссылкам; во время работы кнопка заблокирована.

# Assumptions

- Одна приписка применяется ко всем трекам очереди, включая плейлисты, а не отправляется отдельным текстовым сообщением.
