# Goal

Использовать существующий процесс подготовки MP3 и публикации в Telegram для YouTube без отдельного интерфейса.

# Required behavior

- CLI и TUI принимают HTTPS-ссылки SoundCloud, YouTube-видео (youtube.com/watch и youtu.be) и плейлистов (youtube.com/playlist); источники можно смешивать в одной очереди.
- Из YouTube скачивается только отдельный аудиопоток с конвертацией в MP3 192 кбит/с, не видеофайл. При отсутствии отдельного аудиопотока трек пропускается с ошибкой. Лимит размера и очистка временных файлов сохраняются.
- Ссылка watch/youtu.be на конкретное видео обрабатывает только это видео, даже при наличии параметра list. Для полной очереди пользователь передаёт ссылку playlist?list=….
- Плейлист раскрывается в отдельные видео в исходном порядке. В TUI названия доступны для индивидуального редактирования перед публикацией.
- Сохраняются пустая по умолчанию приписка, переименование названия и MP3, отсутствие ссылок на источник в подписи.
- Рядом с полем ссылок TUI есть кнопка «Очистить»: удаляет ссылки, подготовленные треки и переименования, не меняет приписку; блокируется во время работы.
- Исполнитель берётся из метаданных artist, затем uploader/channel; значения по умолчанию не называют YouTube-трек SoundCloud.
- Ошибки скачивания отдельного видео не останавливают остальные; диагностика не раскрывает секреты.

# Constraints and decisions

- Переиспользуется yt-dlp и общий pipeline. При переименовании приложения в Yet Another Music Downloader основной скрипт стал yamd.py.
- Для полной поддержки YouTube устанавливаются зависимости yt-dlp[default] (включая EJS); документируется JavaScript runtime Deno или явно включённый Node.js подходящей версии.
- Разрешены только известные домены поддерживаемых сервисов; произвольные сайты не добавляются.
- Авторизация, cookies, обход возрастных/региональных ограничений, приватные и платные видео, прямые эфиры не входят в объём.

# Acceptance criteria

- Локально проверены разбор ссылок обоих сервисов, раскрытие YouTube-плейлиста, отдельное видео с параметром list, подпись без ссылок и редактирование названий в TUI.
- Проходят py_compile, CLI --help, pip check и headless-проверка TUI. README содержит примеры YouTube и инструкции по зависимостям.
- Проверки с подменой сетевых вызовов не публикуют сообщения. Реальная загрузка/публикация выполняется только по отдельному согласованию.

# Verification

- Успешны py_compile, CLI --help, проверка невалидного порта (код 2), установка зависимостей и pip check; EJS импортируется.
- Проверены локально с подменой загрузчика: нормализация видео с list, раскрытие плейлиста по порядку, смешанные источники, MP3-параметры, payload sendAudio, название/имя файла, подпись без URL и очистка временных файлов.
- Подтверждено продолжение очереди после ошибки отдельного трека и понятная ошибка при отсутствии runtime для YouTube без блокировки SoundCloud.
- Реальный селектор форматов yt-dlp проверен офлайн: выбирает отдельное аудио и не выбирает совмещённый видеопоток при отсутствии аудио.
- Headless TUI на 100×45 и 80×24: загрузка смешанного списка, переименование перед отправкой, клик «Очистить» после прокрутки, сохранение приписки, фокус поля ссылок и блокировка очистки во время работы.
- Реальные загрузки и запросы Telegram не выполнялись; доступность конкретных видео и сетевые ограничения YouTube не проверялись.
