# Yet Another Music Downloader

**YAMD** — терминальное приложение: SoundCloud / YouTube → аудио MP3 → Telegram-канал.

Поддерживает отдельные треки/видео и плейлисты, редактирование названий каждого трека, необязательную приписку и настройку Telegram в TUI или CLI. Видео не загружается: выбирается отдельный аудиопоток и конвертируется в MP3. Сервер, polling и webhook не нужны.

## Готовая сборка: без Python

Первая сборка — **macOS Apple Silicon (arm64)**. Архив создаётся локально в `dist/yamd-macos-arm64.tar.gz`; бинарники пока не опубликованы в GitHub Releases.

Внешние зависимости:

```sh
brew install ffmpeg deno
```

Нужны `ffmpeg` и `ffprobe`; для YouTube — Deno >= 2.3 (рекомендуется) или Node.js >= 22 в PATH. Для SoundCloud JS-runtime не нужен. Python и активация `.venv` для готовой сборки не требуются.

Распакуй архив, сохраняя **всю папку** `yamd`, включая `_internal`:

```sh
tar -xzf yamd-macos-arm64.tar.gz
./yamd/yamd --configure
./yamd/yamd
```

Либо после локальной сборки:

```sh
./dist/yamd/yamd
```

### Команда yamd из любой папки

Для первой установки из распакованного архива:

```sh
mkdir -p "$HOME/.local/opt" "$HOME/.local/bin"
cp -R yamd "$HOME/.local/opt/"
ln -s "$HOME/.local/opt/yamd/yamd" "$HOME/.local/bin/yamd"
```

Если `~/.local/bin` ещё нет в PATH, добавь в `~/.zshrc`:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Примени `source ~/.zshrc`. Теперь доступны `yamd`, `yamd --configure` и `yamd 'https://youtu.be/VIDEO_ID_11'`. При обновлении замени всю установленную папку, а не только исполняемый файл; пользовательские настройки находятся отдельно.

Сборка ad-hoc подписана средствами PyInstaller, но **не подписана Developer ID и не notarized**. macOS может заблокировать скачанный файл. Не отключай Gatekeeper целиком: используй разрешение запуска в настройках безопасности только для сборки из доверенного источника либо собери её самостоятельно. Для Windows/Linux и Intel Mac необходима отдельная сборка на соответствующей платформе.

## Настройка Telegram

1. Создай бота через @BotFather.
2. Добавь его администратором канала с правом публикации сообщений.
3. В TUI нажми **«Настройки»** или выполни:

```sh
yamd --configure
```

Укажи токен бота и числовой ID канала либо `@username`. Токен вводится скрыто и не передаётся аргументом командной строки. Пустой ввод при редактировании сохраняет прежнее значение. Сохранение не делает сетевых запросов; доступ к каналу и права бота проверяются перед отправкой.

Настройки сохраняются вне приложения:

- macOS: `~/Library/Application Support/yamd/config.json`;
- Linux: `$XDG_CONFIG_HOME/yamd/config.json` или `~/.config/yamd/config.json`;
- Windows: `%LOCALAPPDATA%\yamd\config.json`.

На macOS/Linux каталог имеет права `0700`, файл — `0600`; запись атомарная. **Это не шифрование и не Keychain**: не отправляй конфиг другим людям и не добавляй в Git. При утечке отзови токен через BotFather. Для Windows эти POSIX-права не заменяют настройку ACL; первая проверенная сборка предназначена для macOS.

Приоритет значений для отправки: переменные `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` → сохранённый конфиг → прежний `.env` рядом с `yamd.py` (только при запуске исходников). Настройки предупреждают о переменных окружения, перекрывающих конфиг. Для применения сохранённых значений убери соответствующие переменные из окружения. `.env` не переносится автоматически, не изменяется и не включается в сборку. Готовый бинарник `.env` не читает.

## TUI

```sh
yamd
yamd --tui 'https://www.youtube.com/playlist?list=PLAYLIST_ID'
```

1. Вставь ссылки SoundCloud / YouTube — по одной на строку или через пробел; сервисы можно смешивать.
2. Заполни «Приписка», если нужна. По умолчанию она пустая и между запусками не сохраняется.
3. Нажми «Загрузить список»: программа прочитает названия без публикации.
4. Выбери строку, измени название. Enter или «Сохранить название» применяют правку; при смене строки и отправке она сохраняется автоматически. Пустое поле возвращает оригинал. Изменение применяется к названию в Telegram, подписи и имени MP3; недопустимые символы имени файла заменяются.
5. Нажми «Отправить» или Ctrl+Enter. Приписка добавляется через пустую строку к каждому аудио, включая плейлисты. Ссылки на источник в сообщения не добавляются.

**«Очистить»** у поля ссылок сбрасывает ссылки, список и переименования, сохраняя приписку. Изменение ссылок тоже сбрасывает подготовленный список. Во время обработки очистка и настройки заблокированы.

Tab / Shift+Tab переключают поля; стрелки выбирают строку таблицы. В небольшом окне прокручивай форму. Ctrl+Q, Ctrl+C или «Выход» закрывают приложение. При работающей очереди требуется подтверждение: текущая операция/трек завершится, следующие не начнутся. Текущий трек может быть опубликован — проверь канал перед повтором. Принудительное закрытие терминала безопасного завершения не гарантирует.

TUI требует интерактивного терминала. Повторная отправка после завершения повторно публикует всю очередь.

## CLI

```sh
yamd 'https://soundcloud.com/artist/track'
yamd 'https://soundcloud.com/artist/sets/playlist'
yamd 'https://www.youtube.com/watch?v=VIDEO_ID_11'
yamd 'https://youtu.be/VIDEO_ID_11'
yamd 'https://www.youtube.com/playlist?list=PLAYLIST_ID'
yamd --note 'На вечер' 'https://youtu.be/VIDEO_ID_11' 'https://soundcloud.com/artist/track'
yamd --help
yamd --version
```

Ссылки выше — примеры: подставь реальные ID и ссылки. Поддерживаются HTTPS-ссылки SoundCloud (включая короткие), YouTube `watch?v=…`, `youtu.be/…`, `shorts/…`, `playlist?list=…`, также `www.youtube.com`, `m.youtube.com`, `music.youtube.com`. Произвольные сайты, страницы каналов и поиска YouTube не принимаются.

**Ссылка на видео с `list`** (`watch?v=…&list=…` или `youtu.be/…?list=…`) загружает только одно видео. Для всего плейлиста используй `https://www.youtube.com/playlist?list=…`.

## Ограничения и безопасность отправки

- Каждый трек отправляется отдельным аудиосообщением через Telegram Bot API `sendAudio`.
- Только отдельный аудиопоток (`bestaudio`) → MP3 192 кбит/с. Если такого потока нет, трек пропускается без загрузки видео. Качество выше исходника не становится.
- Файлы больше **49 000 000 байт** пропускаются без скрытого пережатия. Подпись длиннее 1024 UTF-16 единиц не обрезается: трек не публикуется, остальные продолжаются.
- Ошибки отдельных треков не останавливают очередь. Коды выхода: `0` — успех, `1` — ошибки обработки/отправки, `2` — неверные аргументы/настройки, `130` — остановка.
- Временные файлы удаляются при обычном завершении, ошибке или Ctrl+C; принудительное завершение процесса/отключение питания может оставить их в системном temp.
- Постоянной истории и дедупликации нет. После сетевой ошибки сначала проверь канал: Telegram мог принять файл. Автоматического повтора публикации нет.
- Приватный, платный, DRM-защищённый, возрастной и регионально недоступный контент, авторизация/cookies, прямые эфиры и ожидаемые премьеры не поддерживаются. YouTube может запросить авторизацию и для публичного видео; обход ограничений не предусмотрен.
- Скачивай и публикуй только контент, на который у тебя есть права.

## Запуск из исходников

Python 3.10+, FFmpeg и Deno/Node.js для YouTube:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python yamd.py --configure
.venv/bin/python yamd.py
```

Вместо постоянного конфига можно задать переменные окружения либо скопировать `.env.example` в `.env` и заполнить его. Пример содержит вымышленные значения.

## Сборка

На целевой платформе:

```sh
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python tools/build.py
```

Результат: папка `dist/yamd/`, архив `dist/yamd-macos-arm64.tar.gz` и SHA256-файл рядом с ним. Для другой платформы имя архива меняется. Сборка содержит Python, ресурсы Textual, yt-dlp и EJS; FFmpeg, JS-runtime, `.env` и пользовательский конфиг не включаются. `BUILD-INFO.json` фиксирует версии пакетов сборочного окружения; лицензии зависимостей находятся в `licenses/`. Побитовая воспроизводимость архива не гарантируется.

Чтобы обновить yt-dlp в исходниках:

```sh
.venv/bin/python -m pip install --upgrade 'yt-dlp[default]'
```

Для готового приложения после обновления зависимостей нужна новая сборка.

Telegram Bot API: https://core.telegram.org/bots/api#sendaudio
