# Goal

Сначала добавить настройку Telegram в приложении, затем собрать и проверить автономную поставку для текущей платформы macOS arm64, после этого опубликовать исходники в GitHub.

# Required behavior

- В TUI появляется кнопка «Настройки» с полями токена Telegram-бота и ID/@username канала; ввод токена скрыт. Настройки недоступны во время загрузки/отправки.
- CLI предоставляет --configure: интерактивный ввод через терминал, токен через getpass, без передачи секрета аргументом командной строки. Существующие запуски со ссылками сохраняются.
- Настройки можно сохранить и изменить; пустой ввод при редактировании сохраняет существующее значение. Сохранение проверяет заполненность и базовый формат без сетевого обращения и публикаций.
- После сохранения новые настройки применяются к следующей отправке без перезапуска приложения; права бота по-прежнему проверяются перед публикацией.
- Токен не выводится в статус, логи, сообщения ошибок, справку и артефакты сборки.

# API / Data

- Единый конфиг вне проекта и исполняемого файла: на macOS ~/Library/Application Support/yamd/config.json.
- JSON содержит bot_token и chat_id; каталог создаётся с правами 0700, конфиг записывается атомарно с правами 0600. Это обычный файл с ограниченным доступом, не шифрованное хранилище.
- Приоритет значений: явные переменные окружения → сохранённый конфиг → прежний .env рядом со скриптом (только при запуске исходников).
- Экран настроек объясняет, если переменные окружения перекрывают сохранённые значения. Существующий .env автоматически не переносится и не изменяется.
- Отсутствующий конфиг допустим; повреждённый/недоступный конфиг даёт понятную ошибку без содержимого и секретов.

# Architecture

- Чтение/сохранение настроек вынесены в общий модуль yamd_config.py, используемый CLI и TUI.
- По запросу пользователя переименованы исходники в yamd.py и yamd_tui.py; после завершения операций локальная папка переименовывается в yet-another-music-downloader.
- Сборка PyInstaller включает Python, зависимости и ресурсы Textual / yt-dlp / EJS; .env, пользовательский конфиг и прочие локальные секреты не включаются.
- Для первой поставки используется каталог с исполняемым файлом и зависимостями (onedir), упакованный в архив yamd-macos-arm64.tar.gz. Артефакты размещаются в dist/ и исключены из Git.
- FFmpeg/ffprobe и Deno либо Node.js остаются внешними зависимостями; их отсутствие диагностируется. Они не устанавливаются сборочным скриптом.
- Предусмотрена воспроизводимая команда сборки и инструкция установки команды yamd в пользовательский PATH без sudo.

# GitHub publication

- После успешных проверок создаётся публичный репозиторий yet-another-music-downloader в аккаунте, авторизованном в GitHub CLI (gh); при отсутствии авторизации пользователь выполняет gh auth login самостоятельно.
- Перед первым коммитом настраивается .gitignore: .env и его локальные варианты, .venv, пользовательские настройки, .pi с историей/логами, build/, dist/ и временные файлы не включаются.
- .env.example содержит только вымышленные значения, не реальные идентификаторы пользователя.
- Состав первого коммита проверяется на секреты без вывода найденных значений. При обнаружении возможного секрета публикация останавливается до устранения.
- Публикуются исходники, документация и конфигурация сборки. Архив сборки остаётся локальным; GitHub Release и загрузка бинарников не входят в запрос.
- Если репозиторий с таким именем уже существует, его содержимое и видимость не изменяются без дополнительного согласования.

# Out of scope

- Изменение реального токена пользователя и пробная публикация при разработке/сборке.
